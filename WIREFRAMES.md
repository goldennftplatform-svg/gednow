# GED Now screen map

The original working wireframes are preserved in `original-abby123/index.html`, `css/styles.css`, and `js/app.js` within that folder.

| Abby 123 pattern | GED Now screen | Learner action |
| --- | --- | --- |
| Welcome stage + activity tiles | Learning studio: welcome → primary action → six practice cards | Start with computer basics or choose a subject |
| Tap-and-respond game | Practice: set name → position → short source/example → question → controls | Type, edit, or select an answer; go back to revise |
| Quest/progress dashboard | Review: score → each answer and explanation → next action | Retry, choose another subject, or open the Washington guide |
| Browser-local progress controls | Studio: completed count + latest result per card → clear results | Resume study on the same device or clear it for the next learner |
| Local server and installable tablet shell | Windows launcher → local/private LAN site → install on localhost/HTTPS | Host a drop-in session with no learner accounts |

**Outreach walkthrough:** Invite a learner to type the sample city. Let them replace a misspelled word and practice submitting a form. Ask which academic area matters most to them today. Complete that short set together, then use one explanation to decide what to study next. When they want an official next step, open the Washington guide to find local classes or check state testing rules.
